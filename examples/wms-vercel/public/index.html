What you're looking at

Casemaster's 164-table WMS app is unchanged on disk: the same .cms files declare BOs, pages, and page actions. The classic runtime renders them as Bootstrap-4 HTML. The @casemaster/admin package adds a thin JSON adapter that exposes the same data through /api/v1/*, then a polished React SPA consumes that contract — yielding a 2026-class admin experience without a single line of business logic moving.

  • 📦 Same Postgres schema; same auth; same bo.persist writes.
  • ⌨️ Cmd-K command palette, Linear-class shortcuts, dark mode.
  • 📊 Virtualized data grids, optimistic mutations, dashboard composer.
  • 🔌 Runtime-agnostic — works on cms-vercel and the .NET runtime.

What the package adds, ten levels at a time

1. Schema-driven everything

The SPA reads /api/v1/schema once and renders every page from the BO descriptor. New BO? It shows up in the sidebar automatically.

2. Cmd-K everywhere

Fuzzy-search every page, BO, and action. Linear/Notion-class navigation; never touch the mouse.

3. Virtualized data grids

50k rows render at 60fps. Server-side pagination/sort/filter; column reorder, resize, hide.

4. Optimistic mutations

Edits feel instant. On failure, automatic rollback with a clear toast — never silent.

5. Linear-class shortcuts

Press ? for the registry. g i = inventory, g a = ASNs.

6. Page actions, reused

The WMS receive flow runs the existing postReceive via /api/v1/page/wms/inbound/receive — no rewrite.

7. Dark, light, brand themes

CSS-variable design tokens shared with the cms-ui CSS overlay so HTML and SPA themes don't drift.

8. Density toggle for floor use

Compact / cozy / comfortable — operators on tablets get readable rows; supervisors on monitors see more at once.

9. Live updates ready

Postgres LISTEN/NOTIFY → SSE plumbing scoped per BO; opt-in per page; serverless-friendly.

10. Copilot, BYO key

Cmd-J slide-out turns "show me overdue receipts in zone B" into a filtered list. Privacy-first; off by default.
